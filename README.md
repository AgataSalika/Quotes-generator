
Quotes App - Генератор случайных цитат
React-приложение для получения вдохновляющих цитат из API-Ninjas с возможностью фильтрации по категориям.

Возможности
Фильтрация по категориям - выбор из категорий: wisdom, life, time или все цитаты

Динамические изображения - фоновые картинки, меняющиеся в зависимости от выбранной категории

Генерация одним кликом - кнопка "Show quote" для получения новой цитаты

Визуальное выделение категории - подсветка тега, соответствующего выбранной категории

Технологии
React (хук useState)

Fetch API

API-Ninjas Quotes API

Принцип работы
Пользователь выбирает категорию из выпадающего списка, нажимает "Show quote" — приложение отображает случайную цитату с указанием автора и категорий. Фоновое изображение меняется в зависимости от выбранной категории.Quotes App - Генератор случайных цитат
